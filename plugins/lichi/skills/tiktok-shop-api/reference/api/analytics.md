## Get Video Performances — `GET /analytics/202403/videos/performances`

Doc: https://partner.tiktokshop.com/docv2/page/get-video-performances-202403 · cập nhật 2026-10-13 · scope: creator.video.write, creator.data.live.read.public

### Path: /analytics/202403/videos/performances
### Method: [GET]
### Function Description
Use this US-creator-only API to retrieve TikTok e-commerce video metrics, including anchor_display_rate, click_through_rate, orders, items_sold, and GMV, for the requested videos.
