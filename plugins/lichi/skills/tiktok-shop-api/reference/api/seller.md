## Seller API overview

Doc: https://partner.tiktokshop.com/docv2/page/seller-api-overview · cập nhật 2025-05-27

### Context
Use the Seller API to retrieve to the seller's active shop(s) or check if the seller has permission to manage global products. Our APIs help Selling Partner's extend their services and grow seller businesses on TikTok Shop at scale.
This API is currently commonly used by global sellers to check whether the store has the ability to list global products.
The Seller API helps allows you to programmatically GET an active shop(s) List, and Query whether you have the permission to list global products.
### Important Concepts

* Seller(Object):  In the TikTok Shop platform, the seller object represents an entity or account that represents a seller or merchant who offers products or services for sale on the platform. It typically contains information related to the seller's identity, profile, and settings.  
* **Seller-shop relationship**

![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/45cea3825dad428088ac4008cd7f2a77~tplv-k9wyc2ijk0-image.image)

* **Shop states**

The shop state mechanism in an e-commerce platform refers to the system used to manage and maintain the current state or status of a seller's shop or store on the platform. It involves tracking various aspects of the shop's operations, availability, and visibility to both sellers and buyers. 
![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/42c408fef3fc4d98bb2f37b67afcb945~tplv-k9wyc2ijk0-image.image)

* **Shop region**

The shop region in an e-commerce platform refers to the geographical or jurisdictional area where a seller's shop operates or targets its customers. It helps determine the availability, shipping options, and other localized aspects of the shop's services. 

### TikTok Shop Marketplace Policies
As a Marketplace, TikTok Shop imposes certain policies on sellers to the benefit of both buyers and sellers.

* We support global sellers opening 1 shop for each target selling country.
* For local sellers, since the target sales place can only be sold locally, a seller can only open and operate 1 local shop. 
*  Every seller has a unique shop code and seller ID generated by the platform. Both seller code and ID cannot be modified once created.
* Every seller needs to complete the registration and submit the onboarding information, after approved by onboarding moderation, the seller can start business in the TikTok Shop, which means the shop state is active. 

### Frequently Asked Questions

* What are the different types of sellers? 
   * **Local sellers**: Sellers who sell products within the same country as their registered business entity, and are not involved in import and export trades.
   *  **Global sellers**: Sellers who sell products to multiple countries beyond the country of their registered business entity. They engage in cross-border trade activities, including settlement and logistics.
   *  **Intra-EU sellers**: Sellers whose business entity is registered in one EU country and who sell products to customers in other EU countries.

* What's a Global product? 
   * Global products are applicable to the **global sellers** and **intra-EU sellers** only, local sellers cannot use this feature. In order to improve the efficiency in managing multi-shop products, sellers can manage product information centrally via this global product and apply changes to the product in multiple markets. After uploading global products, sellers can publish them to shops in multiple markets with just one click.

## Get Active Shops — `GET /seller/202309/shops`

Doc: https://partner.tiktokshop.com/docv2/page/get-active-shops-202309 · cập nhật 2026-10-13 · scope: seller.shop.info

### Path: /seller/202309/shops
### Method: [GET]
### Function Description
Retrieves all active shops associated with the authenticated seller account. The response includes each active shop's ID and region.
Target seller: All

## Get Shop Group and Related Shops — `GET /seller/202601/shop_groups`

Doc: https://partner.tiktokshop.com/docv2/page/get-shop-group-and-related-shops-202601 · cập nhật 2026-10-13 · scope: seller.authorization.info

### Path: /seller/202601/shop_groups
### Method: [GET]
### Function Description
Retrieves the product interoperability group and related shops for the authenticated shop. For example, a group can include a U.S. shop and a Mexico shop.
