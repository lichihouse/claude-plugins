# Crie a conta de desenvolvedor

> Nhóm: BRASIL | Jornada do Desenvolvedor / Sua trilha começa aqui! · nguồn: https://open.shopee.com/developer-guide/738

## Escolha um 'Account Type' para ter acesso como desenvolvedor

## Objetivo

Obter acesso como desenvolvedor à Shopee Open Platform para criar aplicações e integrar sua solução às APIs da Shopee.

 

## O que você fará nesta etapa

Nesta etapa você solicitará seu perfil de desenvolvedor. Durante o cadastro será necessário escolher o tipo de perfil, preencher as informações da empresa e enviar a solicitação para análise da Shopee. Após a aprovação, você poderá criar aplicações na Open Platform.

## Documentação

Confira os critérios de cada modelo, passo a passo de solicitação e imagens do fluxo em: [https://open.shopee.com/developer-guide/12](https://open.shopee.com/developer-guide/12) 

## Antes de continuar, você deve saber

- Existem dois tipos de perfil de desenvolvedor.
- O perfil precisa ser aprovado antes da criação de Apps.
- A análise é realizada pela Shopee com base em critérios internos, expostos na documentação original.
- Após aprovado, será possível acessar criar Aplicativos.
