# Test Account e Sandbox V2

## O que é o Sandbox?

O Sandbox é um ambiente de testes da Shopee que permite desenvolver e validar integrações sem utilizar dados ou lojas reais.

## Objetivo

Validar sua integração em um ambiente de testes antes de utilizar uma loja real.

## O que você fará nesta etapa

Você criará uma loja de testes (Sandbox), autorizará essa loja para sua aplicação e poderá simular todo o fluxo de integração antes de publicar sua solução em Produção.

## Fluxo de utilização

1.  Criar uma conta de teste (Sandbox).
2.  Criar uma loja de teste.
3.  Criar uma aplicação Sandbox.
4.  Autorizar a loja de teste para sua aplicação.
5.  Criar produtos de teste.
6.  Criar pedidos de teste.
7.  Validar suas chamadas de API.
8.  Simular o fluxo logístico e acompanhar as mudanças de status do pedido.

## Antes de continuar, você deve saber

- Sandbox e Produção são ambientes totalmente independentes.
- Aplicações Sandbox funcionam apenas com contas e lojas Sandbox.
- É necessário autorizar a loja de teste utilizando o Partner ID de Sandbox.
- Algumas funcionalidades disponíveis em Produção podem não estar implementadas no Sandbox.

## Próximo passo

Com sua aplicação validada no Sandbox, você poderá solicitar o ambiente de Produção (**Go Live**) e iniciar testes com lojas reais.
